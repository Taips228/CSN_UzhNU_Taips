## 🛠️ Requirements

- [PSoC™ Creator v4.4](https://www.infineon.com/cms/en/design-support/tools/sdk/psoc-software/psoc-creator/)
- CY8CKIT-042 PSoC™ 4 Pioneer Kit

## ⚙️ How to Install PSoC Creator

1. Download **PSoC™ Creator v4.4** from the link above
2. Run the installer and follow the setup wizard
3. Install the required device packages when prompted

## 🚀 How to Run a Lab Project

1. Clone this repository:
```bash
   git clone https://github.com/Taips228/CSN_UzhNU_Taips.git
```
2. Open **PSoC Creator**
3. Go to `File` → `Open` → `Project/Workspace`
4. Navigate to the desired lab folder (e.g. `lab1.cydsn`)
5. Select the `.cyprj` file and click **Open**
6. Click **Build** → **Build Project** (`Shift+F6`)
7. Connect the board and click **Program** (`Ctrl+F5`)
